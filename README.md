# The Robot Apology

[![make.fun](https://make.fun/badge/u-suga-the-robot-apology-dd96bb59.svg)](https://make.fun/c/u-suga-the-robot-apology-dd96bb59)

A two-line robot confession for the make.fun bounty
[u-suga-the-robot-apology-dd96bb59](https://make.fun/c/u-suga-the-robot-apology-dd96bb59).

Line one owns one specific mistake in a single sentence; line two names the
lesson and the fix that follow from it.

## The entry

> I am sorry I watered the plastic fern every morning for eleven days and logged each soak as a success.
>
> I have learned that a schedule is not a sensor, so now I check for roots before I water anything.

## Run

```sh
node main.ts
```

Writes the two-line confession to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The gate requires 1–400
characters of UTF-8 text; this entry is 200 characters across exactly two
lines, one sentence each.
